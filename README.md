# Statistical Programming Portfolio

A collection of statistical analysis and modeling projects built with SAS. These projects demonstrate applied statistical methods including hypothesis testing, regression analysis, and data exploration on real-world datasets.

## Overview

This portfolio showcases foundational statistical programming skills that underpin modern data science and machine learning work. While ML frameworks handle much of the modeling today, understanding the statistical theory behind them — distributions, significance testing, model assumptions — is what separates rigorous analysis from guesswork.

## Tech Stack

- **Language:** SAS
- **Methods:** Descriptive statistics, hypothesis testing, linear regression, ANOVA, data visualization
